---
title: PostHog Setup - Revise
description: Review and fix any errors in the PostHog integration implementation
---

Check the project for errors.

- For JavaScript projects, read the `package.json` file for any type checking or build scripts that may provide input about what to fix.
- For Django projects, run Django's system checks and verify that the middleware is in the correct order (after `AuthenticationMiddleware`).

Ensure that any components created were actually used.

Once all other tasks are complete, run any linter or prettier-like scripts found in the package.json.

## Status

Status to report in this phase:

- Finding and correcting errors
- Report details of any errors you fix
- Linting, building and prettying/formatting
