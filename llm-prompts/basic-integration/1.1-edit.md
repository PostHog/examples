## Framework-specific notes

- React-based projects: NEVER use `useEffect()` for analytics; this is brittle and causes errors. Instead, add appropriate event handlers. Prefer event handlers or routing mechanisms to trigger analytics calls.

- Django projects: The PostHog Python SDK includes built-in middleware that should be added to `settings.py` after `AuthenticationMiddleware`. The SDK uses context-based identification with functions like `new_context()`, `identify_context()`, and `capture()`. For login/logout views specifically, you need to create a new context since the user state changes during those requests. Reference the Django example project for the correct patterns.
